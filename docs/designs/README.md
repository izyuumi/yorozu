# Designs

Approved Yorozu specs live here, one Markdown file per feature: `docs/designs/FEATURE.md`.

A spec lands here only after Yorozu approves it and its Goldfish (EGM) review has no 🔴 open, with every 🟡 fixed or contested with a reason.

Goldfish review reports stay in the git-ignored `.egm/` folder and are never committed.
