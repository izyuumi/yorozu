Fixtures are raw Durable Object storage snapshots plus signing keys for relay storage and wire compatibility replay.
Produced by compat.test.ts capture on the source commit named by each fixture's producer field (v0.13.0 for the shipped baseline).
All keys are test-only, generated by the capture tests; never use them outside tests.

Capture tests are skipped unless `VITE_COMPAT_CAPTURE=1`. Set `VITE_COMPAT_PRODUCER` to the source commit SHA; it defaults to `unknown`.
Run from `apps/relay`:

```sh
VITE_COMPAT_CAPTURE=1 VITE_COMPAT_PRODUCER=<git-sha> vitest run -u
```

Capture writes snapshots to `compat-fixtures/captured/<scenario>.json` and also logs each fixture.
Copy captured files by hand to `compat-fixtures/<producer>-<scenario>.json` to include them in replay.
Replay loads only `compat-fixtures/*.json`, excluding `captured/`.
