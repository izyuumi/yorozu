```yaml
type: inference

confidence: 0.78
epistemic_status: inferred

```

## Body sections

- `## Claim`
- `## Supporting evidence`
- `## Counterevidence`
- `## Context and alternatives`
- `## Confidence history`
- `## Verification plan`

Never rewrite an inference as an explicit fact. Revise or retract it when evidence changes.
