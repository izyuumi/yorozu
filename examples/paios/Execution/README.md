# Execution

Operational center for what should happen and what did happen.

- `Queue.md`: continuously prioritized execution items.
- `Pending Approvals.md`: commit-ready actions awaiting the smallest necessary confirmation.
- `Delegation Register.md`: index of authorization records.
- `Purchases.md`: non-secret purchase and delivery summary.
- `Deliveries.md`: waiting items and follow-ups.
- `Logs/`: material action logs.

Queue membership and SOP applicability do not grant authority.
